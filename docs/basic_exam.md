# Basic Exam
## How to Use Jupyter Notebook
- **ノートブックファイル**
    - 概要
    - 使用例
        - コードセル、Markdownセル、出力セル
    - ショートカット集
- **print(), display()**
    - 結果や情報を標準出力に表示する関数。

## Data Types: Numbers, Strings, and Variables
- **数値**
    - int
    - float
- **文字列**
    - '', ""
    - raw文字列
    - f文字列 (フォーマット済み文字列)
- **変数の宣言**
    - 小文字で定義 (例: `var = "abc"`)
- **定数の宣言**
    - 大文字で定義 (例: `PI = 3.14`)
- **型変換**
    - `int()`, `float()`, `str()` など
- **数値演算**
    - 加減乗除、べき乗、剰余
- **文字列操作**
    - 結合、スライス、メソッド (例: `upper()`, `replace()`)

## Data Structures: List, Tuple, Dictionary, and Set
- **リスト**
    - 順序付きで変更可能なコレクション。
- **タプル**
    - 順序付きで変更不可能なコレクション。
- **辞書**
    - キーと値のペアを持つコレクション。
- **セット**
    - 重複を許さない順序なしのコレクション。
- **リスト操作**
    - 要素の追加、削除、スライス、リスト内包表記
- **タプルの特性**
    - イミュータブルな性質と用途（例: 関数の戻り値）
- **辞書操作**
    - キーの存在確認、値の更新、辞書内包表記
- **セット操作**
    - 和集合、積集合、差集合の操作

## Conditional Statements
- **if-else, elif**
    - 条件分岐のバリエーション
- **ネストされた条件分岐**
    - if文の入れ子構造
- **三項演算子**
    - `x if condition else y`
- **match-case**
    - 複数条件に応じた分岐処理を行う構文。

- **while文**

- **break, continue**

- **enumerate, zip**

## Functions

    - 再利用可能な処理をまとめたコードの単位。

## Classes
- **クラス**
    - データと機能をまとめた設計図。
- **メソッドとプロパティ**
    - クラス内で定義された関数と属性。
- **クラスオブジェクト**
    - クラス自体を表すオブジェクト。
- **インスタンスオブジェクト**
    - クラスから生成された具体的なオブジェクト。
- **メソッドオブジェクト**
    - クラスやインスタンスに紐づいた関数。
- **クラス変数とインスタンス変数**
    - クラス全体共有の変数とインスタンス専用の変数。
- **継承**
    - 親クラスの機能を引き継ぐ仕組み。
- **多重継承**
    - 複数の親クラスから機能を継承。
- **抽象基底クラス**
    - 子クラスで実装を強制するクラス。

- **パッケージのインストール**

- **インストール済みパッケージの確認**

- **パッケージの依存関係の確認**
    - パッケージ間の依存関係をチェック。
- **仮想環境での利用**
    - プロジェクトごとに依存関係を管理。
- **requirements.txtの利用**
    - パッケージリストを共有・管理する方法。
- **トラブルシューティング**
    - pip関連の問題の解決方法。
- **pipのアップグレード**
    - pip自体を最新バージョンに更新。
- **便利なpipオプション**
    - 効率的な操作を助ける追加オプション。
